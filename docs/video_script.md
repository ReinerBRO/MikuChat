# 视频口播脚本

我把初音做成了能聊天的桌面应用，支持mac和windows平台，打开就能和她互动。  
这是主界面：左侧是聊天与导航，右侧是状态面板和互动入口。  
先来一句话试试，她会给出带情绪的回复，表情也会跟着变化。  
开启语音后，回答会直接播出来，口型同步，看起来更像真的在说话。  
你也可以发图片，她会理解你发的内容并回应。  

互动和游戏化也有：摸头会触发好感和心情变化。  
通过聊天赚到的葱葱币，可以在商店里换背景。  

生活化功能也做进来了：  
每日miku 推送图片。
Miku News 可以看miku相关资讯，多种分类和来源。
音乐区能播放本地或在线搜索Bilibili。  
记忆画廊会记录有意义的对话，并生成每天的小总结。  

如果你也想部署体验，GitHub项目里已经写了完整部署步骤，包括环境配置和模型下载以及SiliconFlow 账号获取 API Key。  
视频简介里也放了github项目地址和 SiliconFlow 的官网链接，按步骤走就行。  

喜欢的话希望能点一个star。  
某些功能可能需要魔法。
