# 视频口播脚本

我把初音做成了能聊天的桌面应用，打开就能和她互动。  
这是主界面：左侧是聊天与导航，右侧是状态面板和互动入口。  
先来一句话试试，她会给出带情绪的回复，表情也会跟着变化。  
开启语音后，回答会直接播出来，口型同步，看起来更像真的在说话。  
你也可以发图片，她会理解你发的内容并回应。  

场景方面可以一键切换，从温馨到赛博，再到和风，氛围完全不一样。  
还有 3D 形态的 Miku，能旋转查看，和 Live2D 一样有互动感。  

互动和游戏化也有：摸头会触发好感和心情变化。  
通过聊天赚到的葱葱币，可以在商店里换背景和服装。  

生活化功能也做进来了：  
Miku News 可以看资讯，音乐区能播放本地或在线歌曲。  
记忆画廊会记录有意义的对话，并生成每天的小总结。  

如果你也想部署体验，GitHub 简介里已经写了完整步骤，照文档操作即可。
