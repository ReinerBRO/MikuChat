# MikuChat 视频制作建议

## 标题候选
1. 我做了一个会说话的初音 AI 伴侣：MikuChat 全功能演示
2. Qwen3-VL + GPT-SoVITS：本地可用的初音聊天桌面应用
3. Live2D + 3D 双形态初音，带音乐与新闻聚合的聊天应用

## 简介建议
MikuChat 是一个以初音未来为主题的 AI 陪伴应用，支持图片聊天、语音合成、Live2D 情绪互动与 3D 角色展示，并内置音乐播放与资讯聚合。  
本视频快速展示它的核心功能与使用方式。项目地址和运行说明在简介中。

## 视频内容规划（2-4 分钟）
### 1. 3 秒钩子
- 画面：Miku 开口说话 + Live2D 表情变化
- 旁白：一句话点题，比如“我把初音做成了能聊天的桌面应用”

### 2. 产品总览（10-20 秒）
- 画面：主界面快速扫过（聊天区、导航栏、状态面板）
- 强调：场景切换、情绪驱动表情、语音合成、3D 模型

### 3. 核心聊天体验（30-60 秒）
- 画面：发送文字 -> 返回带情绪标签的回复
- 演示：开启语音播放，观察口型同步
- 演示：发送图片，展示理解与互动

### 4. 互动与游戏化（30-45 秒）
- 画面：摸头/互动触发好感与心情变化
- 画面：葱葱币、商店购买背景/服装

### 5. 生活化功能（30-45 秒）
- 画面：Miku News 资讯列表
- 画面：音乐搜索/播放（本地或 B 站）
- 画面：记忆画廊（日记/每日总结）

### 6. 部署提示（10-20 秒）
- 画面：GitHub 仓库页或 README 快速扫过
- 旁白：部署步骤已写在 GitHub 简介，按文档即可复现

### 7. 结尾引导（5-10 秒）
- 画面：应用主界面
- 旁白：点个关注/三连，留言想看的功能

## 拍摄清单（按优先级）
- Live2D 表情变化与口型同步
- 3D 模型旋转与动画
- 图片聊天与语音回复
- 场景切换与背景/服装更换
- Miku News 与音乐播放
- 记忆画廊/日记总结
